# LG-R2a next-step rule

No next experiment starts automatically. The completed result is **Result B**,
and `LG_R2B_AUTHORIZED=false`.

If every integrity, incremental-value, sensitivity, robustness, and
deployability check passes, LG-R2a is Result A and only authorizes a separate
LG-R2b design review for a small real same-state candidate counterfactual
pilot. That later milestone would require new data authority and a new frozen
protocol.

If action signal is local but unstable, LG-R2a is Result B. Candidate ranking
remains prohibited; the evidence should decide whether to improve target
locality, action representation, or natural-failure balance.

That is the observed case. C improves sparse failed-placement and terminal
ranking and responds to real-action permutation, but it misses the primary
progress threshold and reaches only 3/5 short-progress folds. The next review
should prioritize a better-balanced source of local natural outcomes or a
separately scoped explicit-dynamics representation. A larger MLP, more steps,
or direct candidate ranking is not justified by this evidence.

Before any new-data proposal, the 39 available local-event-positive cached
windows should be treated as the binding support limit. Any future
same-state/counterfactual collection requires a new milestone and explicit
authorization; LG-R2a itself grants none.

If numeric action adds no independent value and permutation does not matter,
LG-R2a is Result C. The current failure-head route stops. A larger MLP or broad
hyperparameter search is not an authorized response. Point-flow
representations, faithful replay, or true same-state data would require
separate milestones.
