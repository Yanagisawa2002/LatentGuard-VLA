# 项目简介（中文）

LatentGuard-VLA 是一个面向机器人动作片段的、以证据契约为核心的验证框架。我从零实现了与具体模拟器解耦的数据模型、确定性动作扰动、证据类型、精确状态成对回放、盲选择和事务化恢复，并通过固定版本与兼容性身份的 ManiSkill PickCube 适配器完成物理回放验证。最终数据链从 60 条源轨迹和 360 个状态锚点生成了 2,880 个强模拟器验证的反事实结果，并在任何未见结果进入之前冻结模型、阈值和选择清单。

项目取得了明确的单步正结果：时序验证器盲选成功率为 98.33%，随机基线为 88.89%；视觉验证器在外部标准域达到 98.89%，在固定强相机与光照偏移下均为 98.06%。同时，项目保留了关键负结果：将蒸馏视觉选择器反复用于闭环后，成功率只有 73.33%，而固定主策略为 100%。随后设计的保守门控在干净场景保持 100% 成功且零干预，在受控故障注入下把成功率从 73.33% 提升到 80.00%，干预率仅 1.17%，但覆盖故障的召回率仍只有 4.03%。

最终发布强调可审查性：所有公开指标都绑定到已提交报告的摘要与 JSON 字段；正、负和部分支持结论严格区分；原始数据、图像、状态、检查点与缓存不进入 Git。该项目不声称通用机器人安全、真实机器人鲁棒性、跨任务/跨机器人迁移、VLA 泛化、语言验证或 LangMani 性能提升。
